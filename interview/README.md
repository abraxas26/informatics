# 생기부 기반 대입 면접 준비

정적 웹앱(빌드 도구 없음).

- **로컬**: `interview/index.html` 을 브라우저로 그냥 열면 됩니다(`file://` 지원). `index.html`·`app.js`·`style.css`·`data/` 폴더를 통째로 옮기면 어디서든 동작합니다.
- **웹 서버 / GitHub Pages**: 그대로 올리면 됩니다. <http://localhost:8765/interview/> 처럼도 확인 가능(`py -m http.server 8765`).

`file://` 에서는 `fetch()` 가 CORS 로 막히므로, 데이터를 JSON 대신 **전역 변수에 담는 `.js` 파일**로 내보내 `<script>` 로 읽습니다. 대학별 데이터와 검색 인덱스는 필요할 때 `<script>` 를 동적으로 붙여 지연 로딩합니다.

단, 4번 메뉴의 Gemini 호출과 PDF 업로드(pdf.js CDN)는 인터넷 연결이 필요합니다.
**모의 면접 녹화(카메라·마이크)는 보안 컨텍스트에서만 열립니다** — `file://` 로 연 경우에는 쓸 수 없고,
`py -m http.server` (localhost) 나 https 주소로 접속해야 합니다. 문항 연습과 타이머는 `file://` 에서도 됩니다.
드물게 브라우저 보안 설정 때문에 `file://` 에서 Gemini 호출이 막히면, 위의 `py -m http.server` 로 열어서 쓰면 됩니다.

## 개인정보

### 생기부 자동 마스킹

업로드·붙여넣기한 생기부는 **브라우저 안에서** 먼저 가려진 뒤 입력창에 표시됩니다.
원문은 어디로도 나가지 않고, 입력창에 보이는 내용이 실제로 전송되는 전부입니다.
(`app.js` 의 `PII_RULES` · `maskPII` · `scanCritical`)

| 자동으로 가리는 것 | 방식 |
| --- | --- |
| 인적·학적사항 표 전체 | 블록째 삭제 (성명·주민번호·주소·전화가 대개 여기 모여 있음) |
| 주민등록번호 | `******-*******` (하이픈 없는 13자리도 포함) |
| 휴대전화 · 일반전화 · 이메일 | 형태만 남기고 치환 |
| 주소 · 생년월일 · 수험번호 · 학번 | 라벨 뒤 값 치환 |
| 출신 초·중·고 학교명 | `○○고등학교` (지원 **대학교**명은 분석에 필요하므로 유지) |
| 학년/반/번호 | `3학년 ○반 ○번` (학년은 분석에 필요해 유지) |
| 직접 지정한 이름 | 입력칸에 쉼표로 적은 본인·친구·교사 이름을 본문 전체에서 치환 |

전송 버튼을 누르면 마스킹을 한 번 더 돌린 뒤, **더 느슨한 패턴**(`CRITICAL_RULES`)으로 다시 훑어
주민등록번호·전화·이메일 형태가 남아 있으면 **전송을 차단**합니다.

### 자동으로 가려지지 않는 것 — 눈으로 확인하세요

- **사람 이름**: 라벨(`성명 :`) 없이 본문에 등장하는 이름은 자동 식별이 불가능합니다.
  → 이름 입력칸에 쉼표로 적어 주세요.
- 봉사·실습 기관명, 대회명, 동아리 고유명, 병원·회사명 등 간접 식별 정보
- 스캔 이미지 PDF(텍스트 레이어 없음)는 애초에 글자를 못 읽으므로 붙여넣기로 넣어야 합니다.

### 녹화물

카메라·마이크로 찍은 영상과 음성은 `MediaRecorder` 로 **브라우저 메모리에만** 만들어집니다.
서버로 올라가지 않고, 페이지를 닫으면 사라집니다. 남기고 싶으면 [⬇ 내려받기] 로 직접 저장해야 합니다.

### 남아 있는 위험

- 마스킹 후의 본문은 **사용자의 API 키로 Google Gemini API에 전송**됩니다. 이 사이트는 아무것도 저장하지 않지만, Google 쪽 처리 정책은 사용 중인 요금제와 약관을 직접 확인해야 합니다(무료 등급은 품질 개선에 활용될 수 있다고 알려져 있습니다).
- 학생에게 배포한다면 **주민등록번호가 포함된 나이스 원본 대신, 세특·창체 부분만 복사해 붙여넣도록** 안내하는 편이 가장 안전합니다.

- API 키는 브라우저 `localStorage`에만 저장되고 서버로 전송되지 않습니다.
- 기본 모델은 `gemini-3.6-flash` (`app.js` 의 `DEFAULT_MODEL`). 계정에서 쓸 수 없는 모델이면
  안내 문구와 함께 [모델 목록 불러오기] 를 권하고, 목록을 불러오면 `MODEL_FALLBACK`
  순서(3.6-flash → 3-flash → 2.5-flash → flash → pro)로 자동 선택합니다.
- 생기부 본문은 사용자의 키로 Google Gemini API에 직접 전송됩니다. 이 사이트는 아무것도 저장하지 않습니다.
- 화면에 이름·학교명 등을 지우고 입력하도록 안내하고 있습니다.

### 재생성 방법

원본 PDF를 손에 둔 상태에서 (`tools/parse_*.py` 상단의 `SRC` 경로 수정) PyMuPDF가 필요합니다.

```bash
pip install pymupdf
py tools/parse_ulsan.py  ulsan.json
py tools/parse_gn.py     gn.json
py tools/parse_sejong.py sejong.json
py tools/parse_gusul.py  gusul.json
py tools/parse_jinsim.py jinsim_q.json
py tools/parse_sejong.py   sejong2020.json "<2020 길라잡이 pdf>"    # 같은 파서, 원본만 다름
py tools/parse_chungbuk.py "<충북 pdf>" cb_case1.json 2025학년도 "충청북도교육청 「…」"
py tools/build_data.py   data          # 위 5개 json 을 build_data.py 의 상위 디렉터리에 두고 실행
py tools/build_common.py data
py tools/build_qindex.py data
py tools/emit_js.py      data          # data/*.json -> data/*.js (JSON 은 삭제됨)

py tools/parse_jesimun.py  jesimun.json           # 제시문 기반·MMI
py tools/render_pages.py   jesimun.json data/jesimun "<부산 pdf>" p   # 원본 쪽 이미지
py tools/parse_sejong2027.py     sejong2027.json    # 2027 전형 정보 (build_data 가 함께 읽음)
py tools/parse_sejong_jesimun.py sejong_jesi.json   # 세종 제시문 기출
py tools/render_pages.py   sejong_jesi.json data/jesimun "<세종 제시문 pdf>" s
py tools/build_jesimun.py  data jesimun.json sejong_jesi.json
```

`build_data.py` 는 중간 산출물(`ulsan.json` 등)을 스크립트 디렉터리의 부모에서 찾습니다.
`data/` 를 지우고 다시 만들면 되고, 마지막에 `emit_js.py` 까지 실행해야 앱이 읽습니다.

## 알려진 한계

- 후기는 응시생이 기억에 의존해 작성한 기록이라 실제 문항·표현과 다를 수 있습니다.

- 전형 방법과 면접 방식은 매년 바뀌므로 반드시 지원 대학 최신 모집요강을 확인해야 합니다.
